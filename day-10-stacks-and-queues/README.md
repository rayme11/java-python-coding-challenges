# Day 10: Stacks & Queues

## Topic: Stacks & Queues (LIFO/FIFO)

### Why interviews care:

*   Essential for understanding fundamental data structures.
*   Used in algorithms like depth-first search (DFS) and breadth-first search (BFS).
*   Common for problems involving backtracking, parsing, and managing function calls.

### Learning Objectives:

*   Understand the Last-In, First-Out (LIFO) principle for Stacks.
*   Understand the First-In, First-Out (FIFO) principle for Queues.
*   Learn how to implement Stacks and Queues using Java's `Deque` and Python's `collections.deque`.
*   Practice common use cases like balanced parentheses validation.

### Daily Workflow:

1.  **Read `Concept10.java` and `concept10.py`:** Understand the core principles and implementations.
2.  **Run the concept files:** Observe the LIFO/FIFO behavior.
3.  **Complete `Exercise10.java` and `exercise10.py`:** Apply your knowledge to a focused problem.
4.  **Commit your work.**
