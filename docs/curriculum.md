# Curriculum — 30-Day Java & Python Interview Prep

Phases build on each other. Each day: 1 concept file per language + 1 exercise.
Estimated time: 30–60 min/day.

---

## Phase 1 — Core Language Fundamentals (Days 1–7)

| Day | Topic | Why interviews care |
|-----|-------|---------------------|
| 01 | Variables, Types & Mutability | Pass-by-value vs reference, immutable strings, `==` vs `.equals()` vs `is` |
| 02 | Control Flow & Loops | Loop idioms, `break`/`continue`, switch/match, off-by-one bugs |
| 03 | Strings & String Manipulation | Most common interview data type; StringBuilder, slicing, common patterns |
| 04 | Arrays & Lists | Fixed vs dynamic, in-place operations, two-pointer technique intro |
| 05 | Functions & Scope | Signatures, default args, `*args/**kwargs`, overloading, lambdas intro |
| 06 | Error Handling | try/catch/except, finally, checked vs unchecked, custom exceptions |
| 07 | **Review Day 1** — mixed mini-challenges from Days 1–6 | Retrieval practice |

## Phase 2 — Data Structures (Days 8–14)

| Day | Topic | Why interviews care |
|-----|-------|---------------------|
| 08 | Hash Maps / Dictionaries | #1 interview data structure — frequency counting, grouping |
| 09 | Sets | Deduplication, membership tests, set algebra |
| 10 | Stacks & Queues | LIFO/FIFO, balanced parens, deque |
| 11 | Linked Lists (conceptual + impl) | Pointer manipulation, classic interview category |
| 12 | Sorting & Comparators | Custom sort keys, Comparable vs Comparator, stability |
| 13 | Big-O & Complexity Analysis | How to talk about your solution's cost — every interview |
| 14 | **Review Day 2** — timed data-structure drills | |

## Phase 3 — OOP & Language Idioms (Days 15–21)

| Day | Topic | Why interviews care |
|-----|-------|---------------------|
| 15 | Classes & Objects | Constructors, instance vs static/class members |
| 16 | Inheritance & Polymorphism | Overriding, `super()`, interfaces/ABCs |
| 17 | Encapsulation & Design Basics | Getters/setters vs properties, immutability patterns |
| 18 | Iterators & Generators / Streams | Lazy evaluation, Java Streams API vs Python generators |
| 19 | Comprehensions & Functional Idioms | map/filter/reduce, list comprehensions — write idiomatic code |
| 20 | File I/O & JSON | Real-world glue: read/write files, parse JSON |
| 21 | **Review Day 3** — build a tiny project combining Days 15–20 | |

## Phase 4 — Interview Patterns & Algorithms (Days 22–30)

| Day | Topic | Why interviews care |
|-----|-------|---------------------|
| 22 | Two Pointers | Palindromes, pair-sum, partitioning |
| 23 | Sliding Window | Substring/subarray problems — extremely common |
| 24 | Recursion & Base Cases | Thinking recursively, stack depth |
| 25 | Binary Search | Sorted data, search-space reduction |
| 26 | HashMap Patterns | Anagrams, group-by, prefix sums |
| 27 | String Patterns | Reversal, rotation, run-length encoding |
| 28 | Mock Interview Drill 1 (Easy) | 45-min timed problem, explain aloud |
| 29 | Mock Interview Drill 2 (Medium) | 45-min timed problem, explain aloud |
| 30 | Final Review & Cheat Sheet | Consolidate your own notes |

---

## After Day 30

- Repeat weak days from your own notes
- Graduate to LeetCode Easy → Medium, one per day, using the same branch workflow
